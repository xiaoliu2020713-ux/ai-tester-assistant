# 电商平台 - 业务规则

> 域标识：`ecommerce`。规则编号（EC-xx）需在生成用例的「备注」中引用。

## 1. 核心实体

| 实体 | 关键字段 | 说明 |
| --- | --- | --- |
| 商品 SPU | spuId、标题、类目、品牌、上下架状态 | 状态：草稿、待审、上架、下架、违规下架 |
| 单品 SKU | skuId、spuId、规格、售价、市场价、可售库存、锁定库存 | 实际下单以 SKU 为最小单位 |
| 购物车 CartItem | cartId、userId、skuId、数量、勾选状态、加入时间 | 单用户单 SKU 唯一 |
| 订单 Order | orderId、userId、订单金额、应付金额、状态、收货地址、创建时间 | 状态：待支付、已支付、待发货、已发货、已完成、已取消、已关闭 |
| 订单明细 OrderItem | orderId、skuId、数量、成交单价、优惠分摊金额 | 退款以明细为单位 |
| 支付单 Payment | payId、orderId、渠道、金额、状态、第三方流水号 | 状态：待支付、成功、失败、已退款、部分退款 |
| 优惠券 Coupon | couponId、类型、门槛、面额、有效期、适用范围、每人限领 | 类型：满减、折扣、无门槛 |
| 用户券 UserCoupon | 券实例、状态、领取时间、使用订单 | 状态：未使用、已使用、已过期、已锁定 |
| 售后 AfterSale | 售后单、类型、状态、退款金额、原因 | 类型：仅退款、退货退款、换货 |

## 2. 业务规则清单

### 2.1 商品与库存
- **EC-01** 只有状态为「上架」的 SKU 可下单；下架/违规商品下单返回 `SKU_OFF_SHELF`。
- **EC-02** 可售库存 = 实物库存 - 锁定库存；下单时先锁库存，支付成功后扣减，超时未支付自动释放。
- **EC-03** 禁止超卖：并发下单时成功扣减总量不得超过实物库存。
- **EC-04** 单次下单同一 SKU 数量上限 200；超过返回参数错误。
- **EC-05** 库存释放必须幂等：同一订单重复取消不得重复释放库存。
- **EC-06** 商品价格变更不影响已创建订单的成交价（订单快照）。

### 2.2 购物车
- **EC-07** 同一用户同一 SKU 重复加入购物车时数量累加，累加上限 200。
- **EC-08** 购物车最多容纳 100 个不同 SKU；超出提示。
- **EC-09** 加入购物车不锁库存；结算时才锁库存。
- **EC-10** 商品下架后购物车条目标记为「失效」，结算时自动剔除或提示。

### 2.3 下单与结算
- **EC-11** 结算时必须校验：SKU 上架状态、库存充足、收货地址有效、实付金额 ≥ 0。
- **EC-12** 订单金额 = Σ(成交单价 × 数量)；应付金额 = 订单金额 - 优惠金额 + 运费。
- **EC-13** 应付金额不得为负；优惠超过订单金额时按 0 处理，不产生负数与余额。
- **EC-14** 创建订单必须携带幂等键（`Idempotency-Key` 或前端 `requestId`）；重复提交只创建一单。
- **EC-15** 订单创建成功即锁定库存，锁定有效期 30 分钟（可配置 5~120）。
- **EC-16** 超过锁定有效期未支付，订单自动关闭并释放库存与优惠券。
- **EC-17** 收货地址必须属于当前用户，否则返回 403。
- **EC-18** 单笔订单明细最多 50 行。

### 2.4 支付
- **EC-19** 只有「待支付」订单可发起支付；已支付订单重复支付须返回明确错误或幂等返回。
- **EC-20** 支付金额必须等于订单应付金额；金额不一致拒绝。
- **EC-21** 支付回调必须验签，且按第三方流水号幂等：重复回调只入账一次。
- **EC-22** 支付成功后订单状态 → 已支付，锁定库存转为实际扣减，优惠券状态 → 已使用。
- **EC-23** 支付超时（30 分钟）后订单关闭；用户再次支付须被拒绝并提示重新下单。

### 2.5 优惠券
- **EC-24** 优惠券校验：状态未使用、在有效期内、满足使用门槛、适用商品范围匹配、未与其他互斥券叠加。
- **EC-25** 同一订单最多使用 1 张平台券 + 1 张店铺券（互斥规则以配置为准）。
- **EC-26** 每张券每人限领 1 张（可配置）；领取总数达到发行量后返回 `COUPON_SOLD_OUT`。
- **EC-27** 下单时锁定优惠券，支付成功后置为已使用；订单取消时释放回未使用状态。
- **EC-28** 有效期边界：起始时间当天 00:00:00 至结束时间当天 23:59:59 可用（含边界）。

### 2.6 履约与售后
- **EC-29** 只有「已支付/待发货」订单可申请仅退款；「已发货」订单需退货退款。
- **EC-30** 退款金额不得超过明细实付金额（含优惠分摊后金额）。
- **EC-31** 部分退款后订单状态转为「部分退款」，全部退款后转为「已关闭」。
- **EC-32** 退款必须幂等，重复申请同一明细退款应拒绝或返回已存在的售后单。
- **EC-33** 已发货订单取消需走售后流程，不允许直接取消。

### 2.7 权限与安全
- **EC-34** 用户只能访问自己的购物车、订单、优惠券、售后单；越权返回 403。
- **EC-35** 管理端接口（上下架、改价、发货、退款审核）普通用户不可访问。
- **EC-36** 未登录访问业务接口返回 401。
- **EC-37** 支付相关接口必须校验签名/凭证，禁止前端可篡改金额。

## 3. 状态机

**订单**：`待支付 --支付成功--> 已支付 --发货--> 已发货 --确认收货--> 已完成`
`待支付 --超时/取消--> 已关闭`；`已支付 --取消/退款--> 已关闭`
禁止：`待支付 --> 已发货`、`已完成 --> 待支付`、`已关闭 --> 已支付`。

**支付单**：`待支付 --> 成功 --> 已退款 / 部分退款`；`待支付 --> 失败`；禁止 `失败 --> 成功`（须新建支付单）。

**优惠券**：`未使用 --> 已锁定 --> 已使用`；`未使用/已锁定 --> 已过期`；`已锁定 --订单取消--> 未使用`。

## 4. 默认参数表（边界值参考）

| 参数 | 默认值 | 允许范围 |
| --- | --- | --- |
| 支付超时 | 30 分钟 | 5 ~ 120 分钟 |
| 单 SKU 下单上限 | 200 | 1 ~ 999 |
| 购物车 SKU 种类上限 | 100 | 1 ~ 500 |
| 单订单明细行上限 | 50 | 1 ~ 200 |
| 满减门槛 | 满 100 减 10 | 面额 < 门槛 |
| 折扣券 | 9 折 | 1 ~ 9.9 折 |
| 运费 | 满 99 免运费，否则 8 元 | 0 ~ 50 |
| 退款时限 | 签收后 7 天 | 1 ~ 30 天 |
