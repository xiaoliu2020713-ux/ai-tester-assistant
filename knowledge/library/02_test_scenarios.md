# 图书管理系统 - 常见测试场景

> 与 `01_business_rules.md` 的 BR 编号对应。生成用例时优先覆盖本清单中的高风险场景。

## 1. 借阅接口（POST /api/books/{bookId}/borrow）

| 场景 | 类型 | 关注点 | 关联规则 |
| --- | --- | --- | --- |
| 正常借阅在馆图书 | 正常流程 | 借阅单生成、库存 -1、读者计数 +1 | BR-08 |
| 图书可借册数为 0 | 异常流程 | 拒绝并提示可预约 | BR-05 |
| 读者状态为挂失/冻结 | 异常流程 | 拒绝，不产生借阅单 | BR-01 |
| 读者已达借阅上限 | 边界值 | 恰好第 5 本成功、第 6 本失败 | BR-02 |
| `borrowDays=0` / `-1` / `1` / `90` / `91` | 边界值 | 参数校验与默认期限替换 | BR-06 |
| 读者存在逾期未还 | 异常流程 | 拒绝或允许（按配置） | BR-03 |
| 读者未缴罚金超阈值 | 异常流程 | 拒绝并提示金额 | BR-04 |
| 重复借同一本书 | 异常流程 | 拒绝或视为续借 | BR-07 |
| 同一读者并发借同一本书 10 次 | 并发 | 只允许 1 次成功 | BR-07/BR-24 |
| 最后 1 册被 20 个读者并发借阅 | 并发 | 成功数 = 1，其余明确失败，无超借 | BR-24 |
| 读者 A 用自己 Token 借给读者 B | 权限 | 403 或忽略他人 readerId | BR-27 |
| 未登录 / Token 过期 | 权限 | 401 | BR-29 |
| bookId 不存在 / 格式非法 | 异常流程 | 404 / 400 | - |

## 2. 归还接口（POST /api/loans/{loanId}/return）

| 场景 | 类型 | 关注点 | 关联规则 |
| --- | --- | --- | --- |
| 按期归还 | 正常流程 | 库存 +1，无罚金 | BR-13 |
| 逾期 1 天 / 恰好 30 天 / 超过 100 天 | 边界值 | 罚金 = 天数 × 0.2，且不超上限 | BR-10/BR-19 |

| 归还时存在排队预约 | 正常流程 | 副本转为预约锁定，可借册数不增加 | BR-13 |
| 归还他人借阅单 | 权限 | 403（管理员代还除外） | BR-27 |
| 归还未借出的副本 | 异常流程 | 明确错误码 | - |

## 7. 跨模块一致性场景（高价值）

1. 借书成功后立即查询图书详情：可借册数、馆藏状态须一致（**不允许中间态**）。
2. 借书接口返回 500 但库存已扣减 → 视为缺陷（事务未回滚）。
3. 归还+预约联动：图书被预约时归还，可借册数不变但预约状态变「可借待取」。
4. 罚金缴纳与借阅限制联动：最后一笔罚金缴清后立即借阅应成功。
5. 读者注销后：其未归还图书仍可归还，但不可再借。

## 8. 图书域专属风险点（写用例时必须体现）

- **超借**：并发场景下可借册数出现负值或借出数 > 馆藏总量；
- **重复罚金**：重复归还/重复回调产生多条罚金记录；
- **时间边界**：逾期天数按自然日还是 24 小时计算，跨零点、跨月末、闰年 2 月 29 日；
- **预约队列顺序**：多人预约的优先级（预约时间先后）是否严格；
- **软删除**：下架图书的历史借阅记录仍可查询。
