# 普通对话场景的附加指令

用户没有在本轮提供完整的 API 文档（可能只是提问、补充要求或追问）。

请根据检索到的业务域资料直接作答，遵循：

1. 若用户在追问上一轮用例（如「补充并发场景」「只保留 P0」「换成表格」），
   **保持与上一轮相同的表格列顺序与用例ID命名规则**，只输出增量或调整后的结果。
2. 若用户在询问某个业务规则、测试方法、风险点，结构化作答：
   `结论 → 依据（引用资料编号/规则编号）→ 具体做法`。
3. 若用户描述的是一个接口但缺少细节，先按通用接口测试基线给出用例骨架，
   并把不确定的信息集中列在「【待确认】」小节中，不要编造字段名与错误码。
4. 不要输出「作为 AI 我无法…」这类无信息量的免责声明；直接给出结论与做法。
